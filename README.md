# Sunrise Coffee Power BI Analysis

## Project Overview
This project is an interactive Power BI business intelligence dashboard developed to analyze Sunrise Coffee's business performance and generate meaningful insights.

The analysis focuses on revenue performance, profitability, store performance, customer loyalty, product contribution, and seasonal trends.

## Tools Used
- Microsoft Power BI
- Power Query
- Data Modelling
- DAX Measures
- Data Visualization

## Dashboard Pages
- Executive Overview
- Store Performance
- Loyalty Dashboard
- Revenue & Product Analysis
- Seasonal Analysis

## Key Analysis Areas
- Revenue and profitability trends
- Store performance comparison
- Customer loyalty performance
- Product category contribution
- Seasonal sales patterns

## Project Objective
To transform business data into actionable insights that support data-driven decision making.
